# Financial Fraud Detection (My Contribution)

This repository contains my individual contribution to a team project on financial fraud detection conducted during the 2026 Erdos Data Science Boot Camp.

## Project Overview

Financial fraud detection is a critical problem in modern financial systems, especially in transaction networks with complex structures.

In this project, we worked with the Elliptic dataset, a graph-structured dataset of Bitcoin transactions, to identify illicit activities.

While the dataset naturally suggests a graph-based modeling approach, our findings revealed that feature-based models significantly outperformed graph neural networks.
